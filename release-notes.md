# ZTweaks 1.4 for Black Ops III Zombies

ZTweaks 1.4 waits for a joining player's own gameplay HUD acknowledgment before applying optional remote spawn/loadout changes and the Point Gain baseline. A slow-loading client no longer has those optional changes attempted merely because the host's round is ready. If the acknowledgment never arrives, ZTweaks leaves those changes unapplied and does not delay the map. The Compatibility report continues to use the paced, on-demand behavior introduced previously.

The client Compatibility page remains available in co-op. DEFAULT remains inert, and unsupported or map-owned systems stay under the map's control.

## Download and install

Subscribe at [ZTweaks on Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3814908789) or download the separately linked **ZTweaks T7 v1.4 by Xep.zip** player package from [GitHub Releases](https://github.com/Xeptix/ZTweaksT7/releases). The Workshop source ZIP is linker input, not a player download.

Workshop users select **ZTweaks** under **Mods** and open **ZTWEAKS SETTINGS** in the Zombies lobby or pause menu. Manual-package users follow the included BOIII, T7x, or t7-compiler installer instructions. Use ZBundle to combine ZTweaks with the other Z mods.

Menus support English and twelve non-English languages. ChatGPT produced the initial translations; please report inaccurate wording with the game, language, setting, current text, and a suggested correction.

# ZTweaks 1.1 for Black Ops III Zombies

ZTweaks 1.1 expands the original gameplay-settings mod with complete menu localization, portable script routes, safer distribution, and stronger runtime compatibility.

## New

- English and twelve non-English menu and notice catalogs, with English fallback and owner-aware translation in standalone ZTweaks and ZBundle.
- Limited BOIII, T7x, and t7-compiler script routes with Windows and Linux installers. The Workshop mod remains recommended because loose scripts cannot provide every fastfile UI or HUD feature.
- Reversible installer ownership: repeat installs preserve original backups, discovery does not create state, verification reports exact installed versions, and uninstall restores pre-existing files.
- Collision-safe shared compiler fragments and shared menu/action contracts preserve native navigation, focus, press-only actions, host locks, changed-setting rows, and translation ownership inside ZBundle.
- Point Gain performs no enabled-only work during map startup and begins sampling only after gameplay is ready. The remaining permanent T7 ownership polls now use bounded timed yields, preventing the T7x black-screen/server-timeout starvation class.
- Compatibility-first gameplay adapters and a source audit covering every stock BO3 Zombies route. Unknown custom-map systems remain map-owned when a safe adapter is unavailable.

All existing match, player, loadout, zombie, world, power-up, GobbleGum, challenge, restart, rotation, and named character-preference settings remain available. DEFAULT continues to preserve map behavior.

Translations were made by AI and may contain mistakes. ChatGPT produced the initial translations; please report inaccurate wording with the game, language, menu or setting, current wording, and a suggested correction.

## Download

Subscribe at https://steamcommunity.com/sharedfiles/filedetails/?id=3814908789 or download the separately linked **ZTweaks T7 v1.1 by Xep.zip** manual package from GitHub Releases. The Workshop source ZIP is not a player download.

## Install

Workshop users select **ZTweaks** under **Mods**. Manual-package users follow the included installer instructions for their BOIII, T7x, or t7-compiler route.

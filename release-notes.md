# ZTweaks 1.3 for Black Ops III Zombies

ZTweaks 1.3 changes how the compatibility report reaches a joining client. The client no longer receives an unsolicited continuous full-report sweep during map loading. Opening the Compatibility page requests a paced snapshot after the round is ready; subsequent changes are sent as updates.

This reduces reliable script-command traffic during co-op joins. Gameplay settings, character preferences, translations, and map-safety checks remain available. DEFAULT stays inert, and unsupported or map-owned systems remain under the map's control.

## Download and install

Subscribe at https://steamcommunity.com/sharedfiles/filedetails/?id=3814908789 or download the separately linked **ZTweaks T7 v1.3 by Xep.zip** player package from GitHub Releases. The Workshop source ZIP is linker input, not a player download.

Workshop users select **ZTweaks** under **Mods** and open **ZTWEAKS SETTINGS** in the Zombies lobby or pause menu. Manual-package users follow the included BOIII, T7x, or t7-compiler installer instructions. Use ZBundle to combine ZTweaks with the other Z mods.

Menus support English and twelve non-English languages. ChatGPT produced the initial translations; please report inaccurate wording with the game, language, setting, current text, and a suggested correction.

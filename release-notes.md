# ZTweaks 1.2 for Black Ops III Zombies

ZTweaks 1.2 adds optional gameplay controls while keeping DEFAULT inert and leaving unsupported or map-owned systems alone.

## New

- Starting-weapon Pack-a-Punch and a registered starting Alternate Ammo Type, plus an independent option to disable stock AATs on compatible upgraded weapons.
- Standard Mystery Box and Fire Sale prices, teddy-bear chance, immediately repeated ordinary box offers, trap prices, powered perk-machine prices, and standard Wunderfizz prices.
- A round-end points bonus and configurable points retained after an ordinary death and respawn.
- Zombie melee damage, health-regeneration delay, rising player damage by round, and damage from registered Pack-a-Punched weapons against standard zombies.
- Optional Max Ammo magazine reload, a One Weapon Slot challenge, and six independent exclusions from ordinary random power-up drops.
- A default-OFF Experimental Tweaks gate for Faster Barrier Rebuild on compatible stock maps. Custom maps and map-authored repair delays remain untouched.
- The shared-menu tab window now stays in place when changing a setting.

Purchase controls use only stock paths where the displayed hint and charged amount stay aligned. Custom map price callbacks, quests, special actors, and unsupported upgrade systems remain map-owned. The compatibility report explains when an option cannot apply.

All previous settings, character preferences, translations, and installer routes remain available. The menus support English and twelve non-English languages. ChatGPT produced the initial translations; please report inaccurate wording with the game, language, setting, current text, and a suggested correction.

## Download

Subscribe at https://steamcommunity.com/sharedfiles/filedetails/?id=3814908789 or download the separately linked **ZTweaks T7 v1.2 by Xep.zip** player package from GitHub Releases. The Workshop source ZIP is linker input, not a player download.

## Install

Workshop users select **ZTweaks** under **Mods** and open **ZTWEAKS SETTINGS** in the Zombies lobby or pause menu. Manual-package users follow the included BOIII, T7x, or t7-compiler installer instructions. Use ZBundle to combine ZTweaks with the other Z mods.

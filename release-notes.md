# ZTweaks 1.5 for Black Ops III Zombies

## New and fixed

- Add a Knife Lunge toggle while keeping the stock behavior by default.
- Correct selected perk retention through ordinary down/revive cycles and clean up retained perks after terminal bleed-out.
- Restore eligible ordinary weapons, ammunition and the selected gun after an ordinary bleed-out respawn, without duplicating quest weapons.
- Implement Starting Room Only using the first sustainable survival area. Introductory travel is allowed; this challenge takes priority over Start Doors Open. Door exits are blocked before payment, and bypasses can return a living player to a previously checked safe position.
- Implement Gun Game progression and One-Box Challenge while preserving map-owned weapons, purchase handling and the first box offer.
- Apply No Pack-a-Punch through normal purchase checks, and make Full Map Pool select among map-approved, eligible weapons without authored weighting.
- Correct Faster Barrier Rebuild discovery for animated stock barriers. Experimental Tweaks remains required.
- Keep stock Alternate Ammo Type rerolls blocked while No Pack-a-Punch is active.
- Apply Knife Lunge changes through the local menu/HUD path after client readiness, preserving the co-op loading safeguards.

Custom quests, special player bodies and replacement systems remain map-owned. Unsupported interactions report a compatibility reason instead of forcing a change. DEFAULT keeps the map's normal behavior. Existing saved settings and each Z mod's separate settings ownership are preserved.

## Download

Subscribe at [ZTweaks on Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3814908789) or download **ZTweaks T7 v1.5 by Xep.zip** from [GitHub Releases](https://github.com/Xeptix/ZTweaksT7/releases).

## Install

Select **ZTweaks** under **Mods** and open **ZTWEAKS SETTINGS** in the Zombies lobby or pause menu. For the compiled player ZIP, extract it and copy its `mods` folder into your Black Ops III directory, producing `mods/ztweaks/zone/`. Script editions use their separate BOIII, T7x or t7-compiler installer instructions. The Workshop source ZIP is linker input, not a player download.

Use ZBundle when combining ZTweaks with the other Z mods. The full mod supplies the complete settings menu; loose-script routes have the limitations listed in their included instructions.

Menus and notices support English plus twelve non-English languages. Translations were made by AI and may contain mistakes. ChatGPT produced the initial translations; please report inaccurate wording with the game, language, menu or setting, current text, and a suggested correction.
